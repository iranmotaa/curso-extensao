Slide 2 · HTML

As tags e o "RG" do elemento

Cada tag cria um pedaço da página. E o id é o documento de identidade desse pedaço.

<tag> cria o elemento

Tudo que aparece na tela nasceu de uma tag: <button>, <img>, <h2>.

id="..." é o nome único

Não pode existir outro igual. É por ele que o JavaScript encontra o elemento depois.

index.html

  🎬 Sortear Série/Filme
</button>

Interatividade: :hover

O CSS também percebe o mouse. :hover responde à pergunta: "o que acontece quando o ponteiro passa por cima?"

:hover

Estilo enquanto o mouse está sobre o elemento. É o que faz o botão brilhar.

:active

Enquanto o botão está sendo clicado e segurado. Dá a sensação de "afundar".

Slide 11 · JavaScript

      
Funções assíncronas

      
Buscar na internet demora. O async/await ensina o código a esperar sem travar a página.

    


    

      

        

          
Nem tudo é na hora
O pedido à API leva um tempo. O JavaScript não pode congelar esperando.

        

        

          
async marca a função
Diz que ela pode demorar e vai devolver uma promessa de resposta.

        

        

          
await espera só ali
A função pausa até a resposta chegar — o resto da página continua vivo.

        

        

          
script.js

          
async function buscarSeries() {
  const resposta = await fetch(URL_API);
  return await resposta.json();
}

        

      


      

        
Enquanto a resposta não chega

        

          

            
1 · Alguém clica
A função assíncrona começa a rodar.

          

          

            
2 · O await segura a função
Ela espera o pedido. A página continua respondendo.

          

          

            
3 · A resposta chega
A função continua de onde parou, já com os dados.

          

          
Sem o await, o código segue antes dos dados chegarem.

        

      

    

  


  
  

    

      
Slide 12 · JavaScript

      
Pedindo com fetch

      
fetch é o pedido. await é a espera. .json() abre a embalagem com os dados.

    


    

      

        

          
fetch(URL_API)
Faz o pedido para a API. Ele não traz tudo na hora — devolve uma promessa de que vai trazer.

        

        

          
await
"Espere a resposta chegar antes de seguir." Sem ele, o código continua sem os dados.

        

        

          
resposta.json()
Abre a embalagem e transforma o texto em uma lista que o JS entende.

        

        

          
return dados
Entrega a lista pronta para o sortear() usar.

        

        

          
script.js

          
async function buscarSeries() {
  const resposta = await fetch(URL_API);
  const dados = await resposta.json();
  return dados;
}

        

      


      

        
Passo a passo

        

          

            1️⃣
            
Pede
fetch(URL_API) → o garçom vai até a cozinha.

          

          

            2️⃣
            
Espera
await → o código para ali até o prato chegar.

          

          

            3️⃣
            
Guarda
dados → a lista de séries pronta para sortear.
